# Open-source declaration (R4)

**No closed, paid or hosted-model API is called anywhere in the extraction pipeline or the app.** Extraction runs entirely on a model we fine-tuned ourselves, on local weights, with no network access at inference time. The web app makes no outside requests (fonts are self-hosted, no CDN, no analytics).

Audit (2026-10-09): a search of all source files for OpenAI, Anthropic, Google/Gemini, Cohere, Azure, Bedrock, API keys and hosted-model SDKs found nothing. The only network use is development-time: downloading open datasets and open model weights (Hugging Face, Kaggle) and training on Kaggle notebooks.

Used only for **base-model selection evidence, never in the product**: zero-shot comparisons of open vision-language models (Qwen2-VL, Qwen2.5-VL, Qwen3-VL, and the public CORD-trained Donut), described in `MODEL_COMPARISON.md`. These are open models too, and none of them runs in the application.

Synthetic data: we also train on whole Indian-style bills generated by our own code (`splitsnap/synth.py`), which goes beyond the "light synthetic augmentation" the problem statement explicitly allows. This is disclosed here and in the report; results on real bills are reported separately.

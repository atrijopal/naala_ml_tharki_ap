# Notebooks

| Notebook | Where it runs | What it does | Checked |
|---|---|---|---|
| [`01_train_on_kaggle.ipynb`](01_train_on_kaggle.ipynb) | Kaggle, GPU T4, internet on, with the dataset `urbikn/sroie-datasetv2` added | Clones this repository and runs the data preparation, overfit gate, 16-epoch training in two stages, held-out evaluation and fp16 export, with the same commands and flags as `kaggle/run_kaggle.py` | The commands are the ones the real run used (through the script). The notebook itself has **not** been run end to end on Kaggle; its code cells parse. |
| [`02_inference_and_split_demo.ipynb`](02_inference_and_split_demo.ipynb) | Local, Colab or Kaggle, needs the checkpoint | Reads one bill with per-field confidences, shows what the app would highlight, splits the bill among named people, prints the explanations, applies a manual override | **Run locally cell by cell** (RTX 4050, fp16); all cells ran and the amounts add up to the bill |
| [`03_results_and_figures.ipynb`](03_results_and_figures.ipynb) | Anywhere with matplotlib | Redraws the training curves, test results, before/after, degradation study, calibration trade-off, error breakdown and load test from `results/` | **Run locally cell by cell**; all cells ran |

Open 02 and 03 in Colab (the repository must be reachable from Colab):

* <https://colab.research.google.com/github/atrijopal/naala_ml_tharki_ap/blob/main/notebooks/02_inference_and_split_demo.ipynb>
* <https://colab.research.google.com/github/atrijopal/naala_ml_tharki_ap/blob/main/notebooks/03_results_and_figures.ipynb>

Notebook 02 needs the fine-tuned checkpoint, which is not stored in git (see the main README). On Colab, upload it or mount Drive and set `CKPT`.

The notebooks are generated by `scripts/make_notebooks.py`; edit that file and rerun it instead of editing the JSON.
